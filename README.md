## Platform data projects

- **[TripAdvisor Hotel Review Data Scraper](https://github.com/wwk990630/tripadvisor-hotel-review-data-scraper)** — schema-aware review parsing, pagination guards, privacy-minimized checkpoints, and a documented multi-stage research history.
- **[Expedia Hotel Review Data Scraper](https://github.com/wwk990630/expedia-hotel-review-data-scraper)** — GraphQL response parsing with explicit separation between Akamai/transport evidence and normalized data.
- **[Airbnb Listing Data Scraper](https://github.com/wwk990630/airbnb-listing-data-scraper)** — recursive extraction of embedded listing state with ID deduplication and clear schema-drift failures.
- **[Yelp Review Data Scraper](https://github.com/wwk990630/yelp-review-data-scraper)** — review-edge normalization and privacy-minimized pagination diagnostics that retain state without cursor values.
- **[Agoda Hotel Review Data Scraper](https://github.com/wwk990630/agoda-hotel-review-data-scraper)** — review-envelope validation and explicit ten-point to five-point rating normalization.
- **[Booking.com Hotel Data Scraper](https://github.com/wwk990630/booking-com-hotel-data-scraper)** — an evidence-bounded challenge-state and checksum experiment for scraper-oriented protocol research.

Each repository is independently installable, bilingual, offline-tested, and contains only artificial fixtures.
